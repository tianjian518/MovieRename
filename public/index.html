快速说明

MovieRename 从 MoviePilot 精简而来，仅保留重命名 + 整理 + TMDB 识别功能。

• 支持存储后端：本地 Alist/OpenList 阿里云盘 115 SMB Rclone
• 完整保留原版分类体系：华语电影、外语电影、国产剧、欧美剧、动漫、纪录片等全部沿用
• API 文档：Swagger UI (/docs) · ReDoc (/redoc)
• 健康检查：GET /api/v1/system/global?token=<your_token> 返回 200 即正常

使用流程：在「重命名/整理」标签页输入文件/目录路径 → 先点「识别」查看 TMDB 识别结果 → 确认无误后点「整理」执行重命名并按分类归类。
